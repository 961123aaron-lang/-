# 7 組投資提示詞(繁體中文)

使用前三件事:
1. 查到的股價,先核對日期和來源,再到券商 App 對一次。
2. 沒資料時 AI 可能會編數字。每組都已加上「缺資料就先問我,不要猜」。
3. 資料要標清楚日期與來源。回答有沒有道理,仍要自己判斷。

換掉 [括號] 內容後貼給 Claude。

## 1. 找股票研究方向
```
請你當一位有十年經驗的交易研究員。針對[股票/指數/產業],用我貼上的今日資料,列出最多 5 個值得研究的方向,資料不夠就先列出還缺什麼。每一個都寫清楚參考價位區間、可能的風險位置、風險報酬比,並說明判斷依據,技術面跟基本面各講一點。缺資料就先問我,不要猜。
```
注意:價位只當研究參考,不要直接當成下單指令。

## 2. 看懂線圖
```
我會貼上[股票代號]的日線圖和週線圖。請幫我找出支撐區和壓力區、趨勢線、均線的排列,還有動能指標現在的狀態。最後用一句話告訴我:以這張圖看,多方還是空方比較有利,理由是什麼。圖看不清楚或缺資料就先問我,不要猜。
```

## 3. 看懂新聞影響
```
這是[公司/產業]最近的新聞,我貼在下面(附來源與發布日期)。請整理這則新聞對公司或產業的短期與長期影響、股價可能的波動範圍,還有如果我已經持有,持股部位要不要調整。每一點都要說根據是什麼,缺資料就先問我,不要猜。
```

## 4. 回測交易策略
```
我想驗證這個策略:[例如 5 日均線由下往上穿越 20 日均線時買進,並寫明賣出條件]。請用[股票/指數]過去[期間]的資料模擬跑一次,告訴我勝率、獲利因子、最大回撤,最容易在什麼情況下失效,還有兩個改進方向。沒有真實的歷史資料就直接跟我說,不要用模擬的數字。
```
注意:買進與賣出條件都要自己寫;AI 可能自行補條件或編結果,要核對手續費、交易稅、股息、分割。

## 5. 投資組合健檢
```
這是我的投資組合:[股票代號與比例]。請幫我找出弱點:哪裡曝險太集中、哪些持股容易受相同因素影響而一起漲跌。然後給我一個符合我[保守/穩健/積極]投資取向的再平衡方案,以及市場下跌 20% 時的避險做法,並說明適不適合一般散戶。缺資料就先問我,不要猜。
```
補充:說明這筆錢多久會用到、最多能接受虧多少。

## 6. 檢討交易紀錄
```
這是我最近 20 筆交易,含進出場價和結果:[貼上紀錄]。請幫我找出反覆出現的錯誤、錯過的機會、還有我的行為習慣,例如追高或太早停利。最後給我 3 條個人化的交易規則,讓我下次照著做。缺資料就先問我,不要猜。
```
注意:貼上前先刪掉帳號、姓名、身分證字號。

## 7. 每日交易計畫
```
幫我設計[市場/標的]的每日交易計畫,分成盤前準備、開盤策略、盤中調整、收盤檢討四段。每段列出查看項目與執行時間,整理成可勾選的每日清單,讓我每天照著執行。
```

## 注意事項
- AI 講錯時語氣一樣肯定。價格、財報數字、日期用之前都要回到來源確認。
- 回測只代表過去,不保證未來。
- AI 不知道你的收入、負債、資金何時要用;它給的比例與價位混有未說明的假設,先問它怎麼算的。
- 不要把券商帳號密碼或下單權限交給任何 AI 工具。
- 融資、期貨、選擇權:先弄懂槓桿、追繳與最大可能損失。
